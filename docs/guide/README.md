# Skiff user guide

This guide takes you from a PSP in a drawer to downloading games from your RomM library. It assumes
no technical background: every step says what to do, how to know it worked, and what to do if it
did not.

Set aside about an hour the first time. Most of it is preparing the PSP, which you only do once.

1. [What you need](01-what-you-need.md)
2. [Custom firmware](02-custom-firmware.md): what it is and how to install ARK-5
3. [Wi-Fi](03-wifi.md): getting an old PSP online safely
4. [Install Skiff](04-install-skiff.md)
5. [Connect to RomM](05-connect-to-romm.md)
6. [Secure connections and client certificates (mTLS)](06-secure-connections.md) (optional)

When something goes wrong: [Troubleshooting](troubleshooting.md) · [FAQ](faq.md)

> [!NOTE]
> Skiff is in early development. Pages 1–4 work today. Pages 5 and 6 describe the first release
> and are marked where a feature is not available yet.
