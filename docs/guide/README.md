# Skiff user guide

This guide takes you from a PSP running custom firmware to downloading games from your RomM library
and syncing their saves.
It assumes no technical background: every step says what to do, how to know it worked, and what to
do if it did not.

1. [What you need](01-what-you-need.md)
2. [Wi-Fi](02-wifi.md): getting an old PSP online safely
3. [Install Skiff](03-install-skiff.md)
4. [Connect to RomM](04-connect-to-romm.md)
5. [Secure connections and client certificates (mTLS)](05-secure-connections.md) (optional)
6. [Sync saves](06-sync-saves.md)

When something goes wrong: [Troubleshooting](troubleshooting.md) · [FAQ](faq.md)

> [!NOTE]
> Skiff is in early development. Connecting to RomM (pages 4 and 5) needs Skiff 0.2.0 or newer;
> syncing saves (page 6) needs Skiff 0.4.0 and RomM 5.4 or newer; getting games sent from RomM's
> web UI (page 4) needs Skiff 0.5.0 and RomM 5.4 or newer.
